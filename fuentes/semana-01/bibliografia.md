## Criterio de selección

La entrega prioriza publicaciones de 2025–2026 para justificar tendencias actuales. Las fuentes anteriores se conservan únicamente cuando funcionan como marcos fundacionales vigentes. La documentación de fabricantes se utiliza para patrones técnicos, no como única evidencia de adopción.
