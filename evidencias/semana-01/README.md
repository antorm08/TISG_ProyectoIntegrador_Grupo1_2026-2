## Validación conjunta

Todos los integrantes deben poder explicar:

- El problema y la oportunidad del proyecto.
- El flujo Obra → Partida → Actividad → Tareo/Metrado → Resumen → Histórico.
- El significado de los cuatro anillos del Radar.
- La razón para priorizar calidad de datos y BI antes de IA avanzada.
- Los supuestos que todavía deben validarse.
- Los límites de confidencialidad y alcance.

## Evidencia desde la siguiente semana

Para las próximas entregas, cada aporte debería incluir al menos una evidencia auténtica:

- Commit realizado desde la cuenta del integrante.
- Pull Request y revisión recibida.
- Sección o archivo elaborado.
- Acta o registro de una decisión del equipo.
- Captura fechada de una reunión o sesión de trabajo, cuando sea pertinente.
- Enlace a una PoC, experimento o diagrama editable.
